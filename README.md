# Zirkel-Tool für Sportstunden

Eine mobile App zum Erstellen und Verwalten von Trainingszirkeln für deine Sportstunden.

## Funktionen

- **Startseite**: Zwei Buttons zur Navigation
- **Zirkel einstellen**: Erstelle und konfiguriere neue Trainingszirkel
- **Gespeicherte Zirkel**: Übersicht aller deiner gespeicherten Zirkel

## Installation auf PyDroid

### Schritt 1: Kivy installieren
1. Öffne PyDroid3
2. Gehe zu **Menü → Pip**
3. Installiere das Paket `kivy`:
   ```
   kivy
   pygame numpy
   ```

### Schritt 2: Datei kopieren
1. Speichere `main.py` in PyDroid (z.B. im Ordner `ZirkelTool`)
2. Oder kopiere die Datei direkt in dein PyDroid-Projektverzeichnis

### Schritt 3: App starten
1. Öffne `main.py` in PyDroid
2. Drücke **Run** (Play-Button oben rechts)

## Verwendung

- **Startseite**: Wähle zwischen "Zirkel einstellen" oder "Gespeicherte Zirkel"
- **Navigation**: Zurück-Buttons bringen dich immer zur Startseite
- Die App speichert automatisch deine Daten
